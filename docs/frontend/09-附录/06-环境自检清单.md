# 开发环境自检清单

单元 1 课堂任务。逐项检查并截图记录，任一项不通过先解决再进入后续单元。

> **版本以哪份为准**：教程基线见[工具链与版本清单](03-工具链与版本清单.md)（Node 24 LTS / pnpm 12.4.1）。本仓库实际按 [env-checklist.md](../env-checklist.md)（Node ≥ 22.12 LTS / pnpm ≥ 9）与 `module-01-toolchain/README .md`（pnpm 10 及以上）执行。
> **自检按下表要求走，装依赖以仓库配置为准**；差异清单见[仓库代码与教程对应索引 · 版本基线说明](../仓库代码与教程对应索引.md#7-版本基线说明)。
> 仓库根目录下已有一份可直接打勾的版本：[env-checklist.md](../env-checklist.md)。

## 运行时与包管理

| 检查项 | 命令 | 合格标准 |
| --- | --- | --- |
| Node.js 已安装 | `node -v` | 22.12 LTS 及以上 |
| 版本管理可用 | `nvm -v` 或 `fnm -v` | 能切换 Node 版本 |
| 包管理器已安装 | `pnpm -v` | 12.4 及以上 |
| 镜像可用 | `pnpm config get registry` | 指向可访问的 registry |
| 全局缓存正常 | `pnpm store path` | 输出目录存在且可写 |

## 编辑器与插件

| 检查项 | 合格标准 |
| --- | --- |
| 编辑器 | VS Code 或 WebStorm 已安装并可打开工程目录 |
| Vue 插件 | Vue 官方扩展已启用，`.vue` 文件有语法高亮与提示 |
| ESLint 插件 | 编辑器中能直接看到规则告警 |
| Prettier 插件 | 保存时按配置格式化 |
| 编辑器设置 | 保存自动格式化已开启，缩进与换行符按项目约定 |

## 浏览器与调试

| 检查项 | 合格标准 |
| --- | --- |
| 浏览器 | Chrome 或 Edge 最新版 |
| 控制台 | 能看懂报错堆栈，会看 Network 面板的请求与响应 |
| 元素面板 | 能定位样式来源与被覆盖的规则 |
| 应用面板 | 能查看 localStorage 与 Cookie |

## Git 与协作

| 检查项 | 合格标准 |
| --- | --- |
| Git 已安装 | `git --version` 有输出 |
| 身份已配置 | `git config user.name` 与 `user.email` 均非空 |
| 密钥可用 | `ssh -T git@github.com` 返回成功认证 |
| 仓库可用 | 能克隆本仓库并看到提交历史 |

## 工程跑通

| 检查项 | 命令 | 合格标准 |
| --- | --- | --- |
| 安装依赖 | `pnpm install` | 无报错，`node_modules` 生成 |
| 启动开发服务 | `pnpm dev` | 浏览器能打开页面 |
| 热更新 | 改一行代码保存 | 页面自动刷新可见变化 |
| 构建 | `pnpm build` | 生成 `dist/` 且无报错 |
| 产物预览 | `pnpm preview` | 本地能访问构建产物 |
