### 单元 2 · 包管理与构建

| 现象 | 原因 | 解决方式 |
| --- | --- | --- |
| 沙箱中 `pnpm install` 报 trash 相关错误 | 注入的 safe-delete 钩子拦截 pnpm 的删除动作 | 命令前加 `NODE_OPTIONS=` 清空注入变量 |
| 依赖安装后包目录为空 | 沙箱破坏了 pnpm 的 junction 链接 | 执行 `pnpm install --config.node-linker=hoisted`，并在 `.npmrc` 固化 `node-linker=hoisted` |
| 构建时清空 `dist/` 失败 | 同一安全钩子拦截删除动作 | 构建命令前加 `NODE_OPTIONS=` |
| 移动含 `node_modules` 的目录报 `Device or resource busy` | 目录被开发服务器或其他进程占用 | 关闭对应进程后重试，必要时删除依赖并在目标目录重装 |
| 构建提示 chunk 超过 500 kB | 应用尚未做代码分割 | 后续路由阶段用 `import()` 懒加载页面，完成后重新测量 |
