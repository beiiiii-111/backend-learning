## 2. 构建

```bash
cd campus-activity-admin
pnpm install --frozen-lockfile
pnpm build            # 产物在 dist/
```

要点：

- CI 与本地必须用同一份锁文件，加 `--frozen-lockfile` 避免装出不一样的版本；
- 环境变量在**构建时**注入，改地址要重新构建，不是改服务器上的文件；
- 构建完先 `pnpm preview` 本地看一眼，再上传。
