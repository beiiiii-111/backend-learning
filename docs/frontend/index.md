# 前端工程化开发 · 配套教程

《前端工程化开发》48 学时课程的配套教程，按课程的模块与单元编号组织。
内容从零讲起：每篇先给一个具体场景，再讲写法和原理，最后落到常见错误与练习。

> 本教程已完整纳入当前仓库。教程同时包含已实现练习、后续单元规划、案例需求和综合项目规格；是否已有源码，以[仓库代码与教程对应索引](仓库代码与教程对应索引.md)为准。

| 项目 | 内容 |
| --- | --- |
| 课程 | 前端工程化开发 · 48 学时 · 12 周 |
| 技术栈 | Vue 3 + Vite + Vue Router + Pinia + Element Plus（用户端为 uni-app） |
| 教程规模 | 156 篇，按 10 个部分组织 |
| 配套代码 | 仓库内按课程进度逐步实现，未实现部分明确标为“仅需求”或“未开始” |

## 怎么读这套教程

| 场景 | 读什么 |
| --- | --- |
| 课前预习 | 先读本单元的 `00-单元导学.md`，再读知识点小节，把示例代码跑一遍 |
| 课中动手 | 直接跳到单元末尾的案例与练习，按步骤完成实训任务 |
| 课后复习 | 看每篇的「常见坑」自查，再做「课后练习」，答不上来再回正文 |
| 做项目时 | 查 `06-综合项目/` 的规格文档，查 `09-附录/` 的 API 与报错速查 |

第一次使用建议按这个顺序：
[课程导读](00-课程导学/01-课程导读.md) → [怎么用这套教程](00-课程导学/02-怎么用这套教程.md) →
[开发环境准备](00-课程导学/05-开发环境准备.md) → [12 周课程地图](00-课程导学/06-12-周课程地图.md)。
