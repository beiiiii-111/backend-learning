## 6. 运行与构建

模块二练习工程：

```bash
cd module-02-vue-core/practice-app
pnpm install
pnpm dev
```

构建校验：

```bash
cd module-02-vue-core/practice-app
NODE_OPTIONS= node node_modules/vite/bin/vite.js build
```

本仓库包含多个独立子工程，安装依赖前必须先进入具体工程目录，不要在仓库根目录直接安装。

### 7.1 单元 3 待补齐项

模板 `templates/vue3-vite-starter/` 目前只落地了 ESLint + Prettier + husky + lint-staged，对照 `unit-03-quality-git/` 的规划还差：

1. 安装 `stylelint`、`stylelint-config-standard-scss` 并补样式检查配置；
2. 安装 `@commitlint/cli`、`@commitlint/config-conventional`，让已有的 `commitlint.config.cjs` 真正生效；
3. 在 husky 里补 `commit-msg` 钩子（`pnpm dlx commitlint --edit "$1"`）；
4. 确认 ESLint 是否跟随教程基线升到 10.x，升则同步检查 `eslint.config.js` 的扁平配置写法。

教程里出现的版本号按"课程基线"理解即可，动手时按上表右侧的仓库实际值安装，避免装到和锁文件对不上的版本。
