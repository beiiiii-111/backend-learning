## 需求

给定一份学生成绩数组，渲染成表格：支持按姓名关键字搜索、按班级下拉筛选、按分数与姓名点击表头切换升降序；筛选结果条数实时显示。

## 验收标准

1. 筛选与排序逻辑用计算属性完成，不写副作用
2. 多个筛选条件可组合，结果与条件一致
3. 表头显示当前排序字段与方向
4. 数据为空时显示空状态，不出现空白表格
