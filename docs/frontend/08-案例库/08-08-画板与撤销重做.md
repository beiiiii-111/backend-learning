## 需求

实现一个简易画板：支持画笔与橡皮、线宽与颜色调整、清空画布，以及撤销与重做。

## 验收标准

1. Canvas 尺寸随容器变化时图形不拉伸变形
2. 撤销与重做在任意操作序列下结果正确
3. 历史栈有上限，超出后丢弃最早的记录
4. 使用自定义指令封装事件绑定与清理
