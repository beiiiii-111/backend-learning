## 需求

实现一个确认弹窗组件和一个消息提示组件：弹窗支持标题、内容插槽与确认 / 取消回调；提示支持成功、警告、错误三种类型与自动关闭。

## 验收标准

1. 弹窗挂在 body 下，不受父级样式与 overflow 影响
2. 两处以上的调用点复用了同一份实现
3. 弹窗打开时背景滚动被锁定，关闭后恢复
4. 连续多次调用提示时按顺序排列，不重叠
