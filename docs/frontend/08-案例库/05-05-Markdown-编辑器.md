## 需求

左侧输入 Markdown 文本，右侧实时渲染预览；输入时渲染做防抖处理；提供常用语法的快捷插入按钮。

## 验收标准

1. 输入与预览双向联动，清空后预览同步清空
2. 停止输入约 300 毫秒后才更新预览
3. 渲染结果不直接插入原始 HTML，避免脚本注入
4. 快捷插入后光标位置合理

## 提交要求

目录内包含 `README.md`、`src/`、`notes.md`。`notes.md` 写实现过程中的关键决策与遇到的问题，使用 AI 工具的部分写清提了什么要求、生成了什么、自己改了什么。
